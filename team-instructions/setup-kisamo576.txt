Инструкция для kisamo576 — как сделать свой коммит в AutoGo
================================================================

Это нужно, чтобы в истории репозитория твои изменения были закоммичены
от ТВОЕГО собственного аккаунта, а не от кого-то другого.

0) Доступ к репозиторию
   Попроси владельца репозитория (kisamo576 или того, у кого прав admin)
   добавить тебя как Collaborator на GitHub:
   Settings -> Collaborators and teams -> Add people -> kisamo576
   (если репозиторий уже твой — этот шаг не нужен)

1) Склонируй репозиторий (если ещё не склонирован на твоём ПК)
   git clone https://github.com/kisamo576/AutoGo.git
   cd AutoGo

   Если уже склонирован — просто обнови его:
   cd AutoGo
   git pull origin main

2) Настрой свою личность ТОЛЬКО для этого репозитория
   (не затронет твои настройки git в других проектах)
   git config user.name "kisamo576"
   git config user.email "edima050607@gmail.com"

3) Создай отдельную ветку под свою часть работы
   git checkout -b feature/kisamo576-task

4) Внеси свои изменения в код (тебе скажут, какую часть делать)

5) Закоммить и запушь от своего имени
   git add .
   git commit -m "Краткое описание того, что сделал"
   git push origin feature/kisamo576-task

6) Открой Pull Request на GitHub из ветки feature/kisamo576-task в main
   и подожди ревью/мерж.

Важно: шаг 2 обязателен ДО коммита — иначе коммит уйдёт под твоим
глобальным git-аккаунтом (если он настроен на этом компьютере), а не
с привязкой "kisamo576 / edima050607@gmail.com", как нужно для истории
репозитория.
