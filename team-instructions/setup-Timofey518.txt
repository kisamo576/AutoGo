Инструкция для Timofey518 — как сделать свой коммит в AutoGo
================================================================

Это нужно, чтобы в истории репозитория твои изменения были закоммичены
от ТВОЕГО собственного аккаунта, а не от кого-то другого.

0) Доступ к репозиторию
   Попроси владельца репозитория (kisamo576 или того, у кого прав admin)
   добавить тебя как Collaborator на GitHub:
   Settings -> Collaborators and teams -> Add people -> Timofey518

1) Склонируй репозиторий (если ещё не склонирован на твоём ПК)
   git clone https://github.com/kisamo576/AutoGo.git
   cd AutoGo

   Если уже склонирован — просто обнови его:
   cd AutoGo
   git pull origin main

2) Настрой свою личность ТОЛЬКО для этого репозитория
   (не затронет твои настройки git в других проектах)
   git config user.name "Timofey518"
   git config user.email "timofeyvkk@gmail.com"

3) Создай отдельную ветку под свою часть работы
   git checkout -b feature/timofey518-task

4) Внеси свои изменения в код — твоя задача:

   ЗАДАЧА: реальный премиум-статус пользователя (сейчас кнопка "Купить
   премиум" на premium.html просто показывает красивое модальное окно,
   но нигде не сохраняет, что пользователь стал премиум).

   Что сделать (бэкенд + фронтенд, по образцу уже готового кода в
   server/routes/garage.js/auth.js — структура похожая):
   - В server/db.js добавить в таблицу users колонки:
     is_premium INTEGER NOT NULL DEFAULT 0,
     premium_until TEXT.
   - Создать server/routes/premium.js:
     * POST /api/premium/purchase — требует авторизации, ставит
       is_premium=1 и premium_until = дата +30 дней от текущей,
       возвращает обновлённого пользователя.
     * GET /api/premium/status — отдаёт is_premium/premium_until
       текущего пользователя.
   - Подключить роут в server/index.js: app.use('/api/premium', ...).
   - В middleware/auth.js в payload токена (signToken) добавить
     is_premium, либо просто запрашивать /api/premium/status отдельно.
   - В premium.html: кнопку "Купить премиум" — после показа модалки
     об успехе реально вызывать POST /api/premium/purchase.
   - В profile.html (вкладка "Премиум доступ") и в nav.js (чип
     "Вы вошли как ...") — показывать бейдж "Премиум" и дату окончания,
     если is_premium=1 у текущего пользователя.
   - Добавить 1-2 теста в tests/api.test.js по образцу существующих.

5) Закоммить и запушь от своего имени
   git add .
   git commit -m "Краткое описание того, что сделал"
   git push origin feature/timofey518-task

6) Открой Pull Request на GitHub из ветки feature/timofey518-task в main
   и подожди ревью/мерж.

Важно: шаг 2 обязателен ДО коммита — иначе коммит уйдёт под твоим
глобальным git-аккаунтом (если он настроен на этом компьютере), а не
с привязкой "Timofey518 / timofeyvkk@gmail.com", как нужно для истории
репозитория.
