Инструкция для KlyzhukA — как сделать свой коммит в AutoGo
================================================================

Это нужно, чтобы в истории репозитория твои изменения были закоммичены
от ТВОЕГО собственного аккаунта, а не от кого-то другого.

0) Доступ к репозиторию
   Попроси владельца репозитория (kisamo576 или того, у кого прав admin)
   добавить тебя как Collaborator на GitHub:
   Settings -> Collaborators and teams -> Add people -> KlyzhukA

1) Склонируй репозиторий (если ещё не склонирован на твоём ПК)
   git clone https://github.com/kisamo576/AutoGo.git
   cd AutoGo

   Если уже склонирован — просто обнови его:
   cd AutoGo
   git pull origin main

2) Настрой свою личность ТОЛЬКО для этого репозитория
   (не затронет твои настройки git в других проектах)
   git config user.name "KlyzhukA"
   git config user.email "klyzhuk.anton.007@gmail.com"

3) Создай отдельную ветку под свою часть работы
   git checkout -b feature/klyzhuka-task

4) Внеси свои изменения в код — твоя задача:

   ЗАДАЧА: реальные жалобы на объявления (сейчас кнопка "Пожаловаться"
   на странице ad.html и вкладка "Жалобы" в admin.html — это alert()
   и захардкоженные строки-заглушки).

   Что сделать (бэкенд + фронтенд, по образцу уже готового кода в
   server/routes/garage.js — там есть похожие по структуре эндпоинты
   part_replacements/inspections, можно взять за образец):
   - В server/db.js добавить таблицу ad_reports: id, user_id (кто
     пожаловался), ad_id (числовой id объявления из cars.js — просто
     число, без FK), reason, created_at, status TEXT DEFAULT 'pending'.
   - Создать server/routes/reports.js:
     * POST /api/reports — требует авторизации (requireAuth), принимает
       { ad_id, reason }, сохраняет жалобу.
     * GET /api/reports — только для админа (requireAdmin), отдаёт
       список всех жалоб.
   - Подключить роут в server/index.js: app.use('/api/reports', ...).
   - В ad.html: кнопку "Пожаловаться" (ищи "Жалоба отправлена
     модератору" в коде) — заменить alert на реальный POST /api/reports
     с небольшим промптом/полем для причины.
   - В admin.html вкладку "Жалобы" (tab-reports) — убрать
     захардкоженные <tr> и подгружать реальные данные через
     GET /api/reports при открытии вкладки.
   - Добавить 1-2 теста в tests/api.test.js по образцу существующих.

5) Закоммить и запушь от своего имени
   git add .
   git commit -m "Краткое описание того, что сделал"
   git push origin feature/klyzhuka-task

6) Открой Pull Request на GitHub из ветки feature/klyzhuka-task в main
   и подожди ревью/мерж.

Важно: шаг 2 обязателен ДО коммита — иначе коммит уйдёт под твоим
глобальным git-аккаунтом (если он настроен на этом компьютере), а не
с привязкой "KlyzhukA / klyzhuk.anton.007@gmail.com", как нужно для
истории репозитория.
